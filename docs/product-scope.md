# WaveAlert competition baseline

Theme 02: Connect Communities. Proposed categories: Civic Services & Local Solutions; Environment & Responsible Living; Community Support & Collaboration.
Submission: 7–10 December 2026, closes 23:59 Bangladesh time.
Judging: problem relevance 25%, functionality 25%, UI/UX 20%, innovation 15%, code quality 10%, demo 5%.

## Scope
Flood, drought, cold wave. Public routes without login; citizen, volunteer, rescue coordinator, NGO, government authority, super admin authenticated roles. Farmer is a citizen profile, not a separate role. BN/EN toggle with Bengali default.
Core: official-source monitoring, geographically targeted alerts, map, SOS, community reporting, verified rescue assignment and tracking, volunteers, shelters, relief, communication, analytics, offline read support, authentication/RBAC.
AI candidates: risk assessment, structured bilingual report extraction, duplicate detection, rescue priority recommendations. Prefer deterministic logic where sufficient. Human review for consequential decisions. No automated dispatch or official warning claims. 
## Delivery
First build a bilingual accessible public interface and a working simulated SOS-to-case workflow; next integrate validated data, authentication and persistence. Clearly distinguish simulated, functional, and planned features. Restrict exact victim locations and personal contacts. No real emergency dispatch without authorized partners.
## Submission checklist
Team name/ID, registration email, project description, live URL, repository URL, final commit URL, demo video, isolated demo credentials, AI tools used (ChatGPT used for planning and initial code), theme/categories.
